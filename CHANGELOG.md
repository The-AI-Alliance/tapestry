The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
This project does not publish semantic-version releases yet: development happens
on the [`develop`](https://github.com/The-AI-Alliance/tapestry/tree/develop)
branch and `main` is reserved for occasional "baked" releases. Add entries under
**Unreleased** as changes land in `develop`; when `main` is cut, stamp the
section with the date (or version) and start a fresh **Unreleased**.
